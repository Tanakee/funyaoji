# 画面

画面の一覧と、全画面に共通の決まり。絵（ワイヤーフレームと世界観の案）は [Design の Artifact](https://claude.ai/artifact/2VHDpZQDdaJaP6xuDn49r4) にある。細かい大きさ・位置・動き・文言は、それぞれの画面の Issue に書く。

この文書は大まかな形だけを書く。実装で分かったことがあれば、その PR でこの文書も直す。状態の遷移と操作は [ゲームの進行](game.md) が正本で、この文書と食い違うときは、どちらを直すかを Issue で決める。

## 全画面に共通の決まり

- **大きさ**：スクリーンは 1280×720 で描いた値で、1080p では 1.5倍にする。文字とボタンは、上下 40px・左右 54px の内側に置く。本文の文字は 20px 以上、見出しは 32px 以上、主役の数字は 64px 以上。スクリーンの文は1行20字まで、2行まで
- **画面の下の帯**：1280×720 では高さ 120px で、そのうち下の 40px は余白にする。Canvas の地面の線は帯の上端に合わせる。React と PixiJS は、上下左右の余白と帯の高さを `src/screen/game/layout.ts` から読む
- **カメラ**：ロビーと遊び方では、スタートラインを画面の横の中央に置く。カウントダウンとプレイ中は、左から 40% の位置におじさんの胴を置く。結果では、おじさんが止まった場所を映す
- **スマホの操作**：ボタンは高さ 56px 以上で、画面の下半分に置く。押したときの見た目は、通信を待たずにすぐ出す
- **4人の色と並び**：左ひざ 水色 `#56b4e9`、左もも 紫 `#6a4cc0`、右ひざ 黄 `#fad21e`、右もも 橙 `#c2510e`。画面の上の席は、左からこの順に並べる。左の脚は寒色、右の脚は暖色にし、ももを濃く、ひざを明るくする。値は `src/shared/joints.ts` にある。色を変えるときは、どの色覚でも見分けられるかを、色差（CIEDE2000）と色覚の見え方（Machado ら 2009）で計算して確かめる
- **糸**：画面の上の端の札（席）から、受け持つ部位の先まで引く。ももの人の糸はひざの前、ひざの人の糸はかかとに付く。ももの人は太もも、ひざの人はすねを、その人の色で塗る。引くほど糸が張って太く明るくなり、糸の上の結び玉が上がる。傾けた人の部位と糸が光る。形の印は使わない
- **右下のボタン**：運営のメニュー・全画面・音を、S2〜S7 で同じ位置に、この順で置く
- **言葉**：ルームコード、席、右もも・左もも・右ひざ・左ひざ、もう一度、抜ける、スタート、QRを読み取る、ランキング、寝かせる・立てる、にそろえる

### 色・フォント・刷り

見た目は、世界観6「昭和の運動会ポスター」（Design の Artifact の「6 改」）にそろえる。値は、スクリーンの `src/screen/ui/screen.css`、スマホの `src/phone/phone.css`、Canvas の `src/screen/game/view.ts` の `COLORS` に入れ、画面の部品では色の値を直に書かない。

| 名前 | 値 | 使う所 |
|---|---|---|
| 紙 | `#f3ead7` | 背景 |
| 面 | `#fbf8f0` | 札、ボタン、QR の台 |
| 藍 | `#1f3a68` | 文字、線、おじさんの外形 |
| 藍・控えめ | `#3f5275` | 控えめな文字 |
| 紅 | `#a8282e` | 見出しの版ズレ、順位の印、ゴールテープだけ |
| 土 | `#c99f6a` | 地面 |
| 肌 | `#f2cfae`（陰 `#d9a07a`） | おじさんの顔と腕 |
| らくだ色 | `#c2a682` | おじさんの腹巻き（胴） |

- **フォント**：見出し・結果の数字・掛け声・人数は Zen Old Mincho の 900、本文・ボタン・ルームコード・部位の名前は Zen Kaku Gothic New の 700 と 900。CSS では `--font-display` と本文の変数で選ぶ
- **フォントの置き方**：Fontsource の npm パッケージ（`@fontsource/zen-kaku-gothic-new`・`@fontsource/zen-old-mincho`）を `src/shared/fonts/fonts.css` で読む。字の範囲で分かれたファイルのうち、画面に出る字を含むものだけをブラウザが読むので、文言を足しても作り直しは要らない。フォントが届くまでは端末のフォントで出し、Canvas の文字は最大3秒待ってから作る。Canvas に新しい字を足したら、`src/screen/game/view.ts` の `loadViewFonts` に渡す字にも足す
- **版ズレ**：見出しと主役の数字だけに、紅の版を右に 3px・下に 2px ずらして重ねる
- **網点**：飾りと、おじさんの影の側に、藍の薄い網点を重ねる。文字・QR・ルームコードには重ねない
- **縁取り**：糸とおじさんの外形に、藍の縁を付ける。黄は紙との差が小さいので、縁を外さない
- **紅**：上の表の3つだけに使い、おじさんのまわりに置かない。4人の色、背景の飾りにも使わない

### おじさんの吹き出し

転倒か座り込みでプレイが終わると、おじさんの頭の横に吹き出しが出て、セリフを言う。転倒と座り込みの判定は変えず、判定が出たときに出すだけにする。値は `src/screen/game/speech.ts` の `SPEECH` にまとめてある。

- **出るとき**：転ぶか座り込んだフレームに、顔が `fell` に変わるのと同時に出す。ゴールと切断では出さない
- **消えるとき**：結果の画面でも出し続け、やり直す（カウントダウンに戻る）か、ロビーの練習に戻ると消す
- **場所**：頭の右上（おじさんが進む向き）に置き、しっぽを頭に向ける。右に収まらなければ左に移し、それでも収まらなければ、上下左右の余白と地面の帯の内側に押し込む
- **形**：面の色の札に藍の 3px の縁を付け、右下に藍を薄くずらした影を敷く。紅は使わない。デバッグでは `?debug&bubble=b`（楕円）と `?debug&bubble=c`（叫び）に切り替えられる
- **文字**：Zen Old Mincho の 900、1280×720 で 36px。1行20字まで、2行まで
- **セリフ**：転倒と座り込みで表を分ける。その終わり方で初めて出すときは表の先頭を、そのあとは表を混ぜて一巡させ、同じセリフを続けて出さない

| 終わり方 | セリフ |
|---|---|
| 転倒 | アキレス腱がー！、あいたたた…、膝がー！、明日は筋肉痛だな…、準備運動、しとけば…、母さん、湿布！、昔はもっと走れたんだ、今のはナシ！ |
| 座り込み | 膝がー！、もう立てん…、膝が笑ってる…、ちょっと一服…、腰が抜けた…、あとは若いのに任せた、息が、上がった…、足が棒だ… |

座り込みは、胴の中心が低い状態が `SIT_MS` 続いて終わったときを指す（[ゲームの進行](game.md)の「プレイの終了」）。

### 運営の操作（S2〜S7）

右下の「運営のメニュー」には「ルームを作り直す」を置く。確認画面で決定したら新しいルームに切り替える。プレイ中も利用できる。作成失敗時の継続と通信の手順は [ゲームの進行](game.md#運営のメニューとルームの作り直し) にある。全画面と音のボタンは待つ画面にも出し、ルーム作成の失敗や接続終了のお知らせ画面には出さない。
