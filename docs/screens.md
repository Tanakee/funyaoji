# 画面

画面の一覧と、全画面に共通の決まり。絵（ワイヤーフレームと世界観の案）は [Design の Artifact](https://claude.ai/artifact/2VHDpZQDdaJaP6xuDn49r4) にある。細かい大きさ・位置・動き・文言は、それぞれの画面の Issue に書く。

この文書は大まかな形だけを書く。実装で分かったことがあれば、その PR でこの文書も直す。状態の遷移と操作は [ゲームの進行](game.md) が正本で、この文書と食い違うときは、どちらを直すかを Issue で決める。

## 全画面に共通の決まり

- **大きさ**：スクリーンは 1280×720 で描いた値で、1080p では 1.5倍にする。文字とボタンは、上下 40px・左右 54px の内側に置く。本文の文字は 20px 以上、見出しは 32px 以上、主役の数字は 64px 以上。スクリーンの文は1行20字まで、2行まで
- **スマホの操作**：ボタンは高さ 56px 以上で、画面の下半分に置く。押したときの見た目は、通信を待たずにすぐ出す
- **4人の色と並び**：左ひざ 水色 `#56b4e9`、左もも 紺 `#1f4e9e`、右ひざ 黄 `#f2b705`、右もも 朱 `#c23a1a`。画面の上の席は、左からこの順に並べる。色は世界観を決めたら選び直し、どの色覚でも見分けられるかを色差の計算で確かめる
- **糸**：画面の上の端の札（席）から、受け持つ部位の先まで引く。ももの人の糸はひざの前、ひざの人の糸はかかとに付く。ももの人は太もも、ひざの人はすねを、その人の色で塗る。引くほど糸が張って太く明るくなり、糸の上の結び玉が上がる。傾けた人の部位と糸が光る。形の印は使わない
- **右下のボタン**：運営のメニュー・全画面・音を、S2〜S7 で同じ位置に、この順で置く
- **言葉**：ルームコード、席、右もも・左もも・右ひざ・左ひざ、もう一度、抜ける、スタート、QRを読み取る、ランキング、寝かせる・立てる、にそろえる

### 運営の操作（S2〜S7）

右下の「運営のメニュー」には「ルームを作り直す」を置く。確認画面で決定したら新しいルームに切り替える。プレイ中も利用できる。作成失敗時の継続と通信の手順は [ゲームの進行](game.md#運営のメニューとルームの作り直し) にある。全画面と音のボタンは待つ画面にも出し、ルーム作成の失敗や接続終了のお知らせ画面には出さない。
